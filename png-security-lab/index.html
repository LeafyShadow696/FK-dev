Test corpus

Browser layer

Portable regression, binary inspection and controlled binary editing. Files are processed client-side with WebAssembly and Web Crypto.

Binary layer

PNG signature, chunk lengths, IHDR fields and CRC-32 are visible at byte level. IHDR edits automatically rebuild the corresponding CRC.

Native layer

For memory-safety triage, the corresponding native C/C++ harness should be run separately under ASan/UBSan in an isolated environment.

Workflow

malformed PNG → binary inspection/edit → parser validation → diagnostic code → native sanitizer triage → stack trace → fix → regression test.

Safety

This project intentionally does not contain shellcode, RCE payloads, memory-corruption primitives or auto-execution behavior.
